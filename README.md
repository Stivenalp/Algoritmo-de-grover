# Algoritmo-de-grover
Aplicación del algoritmo de grover en búsquedas no estructuradas: análisis y comparación de la eficiencia de algoritmos de búsqueda con algoritmos cuánticos.
# Notebook algoritmo_tesis_mitc.ipynb
Este notebook realiza un ejercicio NP-Completo en donde se estructura un problema 3-SAT, se diseña a nivel clásico y se estructura un circuito cuántico para solucionar el problema que satisface una ecuación, se puede realizar diferentes compartivas y e iterar el circuito con diferentes ejecuciones para visualizar su comportamiento.
Con esto se logra demostrar una estructura única para resolver un problema NP-Completo con ayuda del Algoritmo de Grover, dado que nos encontramos en la era NISQ no podemos ejecutar el algoritmo en un problema estructurado de mayor tamaño dado el ruido que existen en los qubits actuales es por eso que para este ejercicio usamos 4 clausulas
